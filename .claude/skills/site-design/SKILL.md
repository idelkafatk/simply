# Дизайн idel.blog

Блог автора, а не сервис. Одна колонка 680px по центру, много воздуха, мало слов. Шрифт Rubik везде, включая текст поста. Акцент — закатный оранжевый `#e2703f` в обеих темах, текст на оранжевом всегда белый.

Выкладка правок — скилл `theme-deploy`. Обложки постов — скилл `blog-cover`.

## Правила, которые владелец уже проговорил

Каждое — реакция на конкретную ошибку. Не нарушать.

- **Без разделительных линий.** Ни hairline-бордеров между блоками, ни `·` между словами. Разделять отступами, залитой подложкой (`--surface`) или мягкой тенью у липкой шапки.
- **Меньше текста.** Никаких поясняющих подписей и мета-строк. Структура и отступы вместо слов.
- **Тексты без «вы».** «Ещё почитать», «Осталось подтвердить», «Письмо со ссылкой ушло на …», «Похоже, в адресе ошибка». Не «Читайте», «Проверьте», «Нажмите». Просто, не литературно, без «ИИ-шности».
- **Ховер кнопки — свечение, а не затемнение.** Оранжевая `.btn` при наведении получает оранжевую тень, цвет не меняется. Затемнять или осветлять её владелец отверг.
- **Ничего не прыгает.** `scrollbar-gutter: stable` на `html`. Активный пункт выделяется цветом, а не жирностью, чтобы ширина текста не менялась. Состояния формы (ошибка, отправка, «Осталось подтвердить») — без изменения высоты.
- **Шит ≠ модалка.** Шит прижат к нижнему краю, верхние углы скруглены 20px, во всю ширину. Модалка — карточка по центру. На телефоне (≤640px) окна становятся шитами.
- **Без пустого места снизу.** Карточки и шиты по высоте содержимого. Исключение — шит поиска: фиксированная высота `60dvh`, максимум 520px, список скроллится внутри, чтобы поле не скакало при наборе.
- **Не добавлять сверх оговорённого.** Новые элементы, подписи, фичи — только по просьбе.
- **Сначала искать в теме.** Если похожее уже решено в `~/pet/simply` (поиск, карусель, шаринг, мобильная клавиатура), переносить механику оттуда, а вид оставлять новый.

## Токены — `src/css/site/tokens.css`

| | светлая | тёмная (`html.dark`) |
|---|---|---|
| `--bg` | `#fff` | `#161719` |
| `--surface` (подложки, кнопки `.act`) | `#f6f6f4` | `#1c1f23` |
| `--text` | `#2b2d31` | `#e8eaed` |
| `--muted` | `#6b6f75` | `#8b9198` |
| `--accent` / `--accent-ink` | `#e2703f` / `#fff` | то же |
| `--link` | `#b8501f` | `#f2955f` |

Рамка поля: `color-mix(in srgb, var(--text) 16%, var(--bg))`, при наведении 28%. Не чёрная. Боковой отступ `--gutter`: 24px, на телефоне 16px. Новых цветов не вводить, брать токены.

## Кнопки — `src/css/site/base.css`

| класс | где | вид | ховер |
|---|---|---|---|
| `.btn` (`.btn-sm` 34px в шапке) | «Подписаться» | оранжевая, белый текст, радиус 10px | оранжевое свечение `0 6px 18px -6px` |
| `.m-submit` | кнопка формы подписки | `.btn` высотой 48px, радиус 12px | то же |
| `.act` | «Обсудить», «Поделиться», «Показать ещё» | `--surface`, 44px, радиус 12px, иконка 18px | фон `--text` 9% поверх `--bg` |
| `.ibtn` | иконки в шапке и в окнах | без фона, 36px (44px на телефоне), иконка 20px, `--muted` | фон `--surface`, цвет `--text` |
| `.m-tg` | Telegram, «Уведомления» | без фона, текст с иконкой | лёгкая подложка |
| `.m-close` | «Готово» в окне подписки | тихая заливка, 48px | заливка плотнее |
| `.tag`, `.pn > a` | теги над заголовком, пред./след. | `--surface` | как `.act` |
| `.row` | строка ленты и поиска | без фона | мягкая подложка `--surface`, заголовок не красится |
| `.search-cancel` | крестик закрытия | линия 22px цвета `--text` в зоне 44px, без фона | становится оранжевым |
| `.search-clear` | очистка поля поиска | серый кружок 22px | кружок плотнее, крестик `--text` |

**Крестик закрытия везде один** — как в поиске: тонкий, 22px, цвет текста, оранжевый при наведении, без подложки. В окнах Ghost он нарисован через `::before` с SVG-маской (`M18 6L6 18M6 6l12 12`, `stroke-width 2`), иконка Ghost скрыта.

Новая кнопка — взять один из этих классов. Если нужен новый, у него обязательно есть `:hover`, `cursor: pointer`, `transition` 0.12–0.15s и зона нажатия не меньше 44px на телефоне.

## Загрузка — три точки

Лоадер один: три пульсирующие точки `.dots-loader` (`src/css/site/list.css`, взят с itpecpractice). Текст «Загрузка…» вместо него не писать.

- Кнопка в процессе: класс `.is-loading` + `disabled`. Подпись остаётся в разметке и держит ширину, точки рисуются поверх (`.m-submit`, `.load-more-btn`). Точки на оранжевой кнопке белые.
- Лента подгружается сама при прокрутке, на каждой странице: `.feed-loading-status` с точками. Верхняя полоса `.loadingBar` — только при переходе между страницами, не при подгрузке ленты.
- Поиск: точки в `.search-message`.
- `prefers-reduced-motion`: точки не растут, а мягко мигают.

## Окна

- **Подписка** (`partials/site/subscribe-box.hbs`, `src/css/site/subscribe.css`) — эталон окна. Аватар, «Подписка на блог», поле 48px, кнопка во всю ширину, «или», Telegram и «Уведомления». Карточка 400px, радиус 20px, фон затемнения — чёрный 40% с `blur(4px)`, на телефоне — шит. Тот же блок без окна стоит под постом (`.sub-inline`, в рамке-подложке).
- **Поиск** — шит фиксированной высоты (см. правила выше).
- Открытое окно блокирует прокрутку страницы, страница при этом не сдвигается (место под скроллбар зарезервировано).

## Окна Ghost: Portal и комментарии

Portal (вход, аккаунт, профиль, уведомления) и comments-ui рисуются в iframe того же домена. Стили темы в них не попадают, поэтому `src/js/ghost-frames.js` вставляет туда собранные `ghost-portal.css` и `ghost-comments.css` и переносит `.dark` как `html.simply-dark`.

- Новое окно Ghost стилизовать там же. comments-ui открывает свои окна (`addDetailsPopup`, `reportPopup`, `ctaPopup`, `deletePopup`) в отдельном iframe с `title` = типу окна — список в `FRAMES` в `ghost-frames.js`. Такой iframe помечается `html.simply-comments-popup`.
- Цепляться за `data-testid` и классы Ghost. `!important` — только там, где Ghost пишет inline-стили (акцентный цвет, цвета аватаров).
- В прозрачном iframe поверх страницы `color-scheme` должен совпадать со страницей, иначе браузер рисует под ним непрозрачный белый холст и страница за затемнением пропадает.
- Ghost при открытии окна добавляет `<body>` `margin-right` на ширину скроллбара. У нас место уже зарезервировано, поэтому `body { margin-right: 0 !important }` в `base.css` — не убирать, иначе страница уезжает влево.
- «Powered by Ghost» скрыт. Тексты Ghost на «вы» и английские даты комментариев темой не меняются.

## Проверка перед тем, как показать

Без этого результат не показывать — владелец не обязан сам находить кривое.

1. **Локальный Ghost** `~/ghost-local` (http://localhost:2368, тема — симлинк на репозиторий). После `yarn prod` — `ghost restart` в `~/ghost-local`, иначе Ghost отдаёт старый CSS. `yarn test` должен пройти (standard, stylelint, gscan).
2. **Скриншоты** каждого затронутого состояния: десктоп 1272px, телефон 390px, светлая и тёмная тема, окно открыто и закрыто, гость и подписчик (тестовые подписчики `anna@example.test`, `boris@example.test`; ссылка входа — через Admin API `members/:id/signin_urls`, только локально). Окно браузера может не уменьшаться — тогда телефон проверять iframe'ом 390px того же домена, вставленным на страницу: им можно управлять из скрипта.
3. **Ховеры**: вставить `hover-audit.js` из этой папки на страницу. `audit()` перечисляет элементы без своего `:hover` (MISS) — фон поиска и поле ввода могут его не иметь, кнопки и ссылки обязаны. `forceHover(true)` включает все ховеры сразу — один скриншот с ховером и один без, в обеих темах.
4. **Лоадеры**: добавить кнопке `.is-loading` и `disabled`, снять `hidden` с `.feed-loading-status`, посмотреть точки.
5. Пройти список: выравнивание, отступы, ничего не прыгает, нет линий и `·`, нет «вы», контраст в тёмной теме, текст не обрезан, нет пустоты снизу. Исправить и проверить снова.
